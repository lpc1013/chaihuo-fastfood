========================================
 柴火快餐 · Windows 版  使用说明
========================================

【怎么玩】
  双击「启动游戏.bat」或 ChaihuoFastFood.exe 启动（无需安装，无需联网）。
  全程鼠标操作；空格 / 回车推进对话，Esc 暂停或返回上一层。
  首次进入有一段可跳过的教学动画，共 8 幕：点画面任意处看下一幕，
  右上角「跳过」直接结束；看完之后界面上不会再出现任何教学文字。

  一句话循环：点小票选中这一单 → 点底部木格把配料叠上案板 → 要切的切几刀
  → 烤架 / 炸锅 / 饮料机各盯一条进度条，落在金色窗口里再点一次
  → **每做完一件就拖给客人**（荷叶是暂存架，一次递一件，收齐了才结算）。
  做坏了点右上那枚火苗圆钮，整盘丢回灶膛（成本不退）。
  右上角那一排圆钮从右往左是：声音、营业台账、暂停、菜谱图鉴、紧急补货、灶膛。
  划上去每一枚都有一句说明；台账随时能翻，看的时候当天进度停住，按返回就接着开。

【钱是抛出来的】
  客人收齐他点的全部几件（堡 / 薯条 / 饮料）才结算，结算时把钱**抛在四个酱料那条台面上**：
  银币一枚 1、金币一枚 10。**鼠标滑过硬币就自动拾进钱包——没捡到的不算钱。**
  第 2 天起，硬币在地上放太久（默认 6 秒）会走来一位收币人，一枚一枚往兜里装。
  **点他可以打断他，并且把他已经拿走的钱全部抢回来**（参考沙威玛）；
  等他走出画面，那笔钱才真的算丢。所以忙不过来时优先捡金币（一枚顶十枚银币）。
  打烊之后台面上没捡的钱**归你**——最后一个客人之后不再有收币人。
  台账和结算页里的「收入」是**实收**；当天真被收走过，结算页会多一行「没捡到的钱」，
  台账那一格写成 "520-25"（实收-被收走）。
  这些数值都能在 user://config/economy.json 的 coins 一节里改：
  gold_value / silver_value / sweep_after / collector_from_day / pickup_radius /
  steal_gap（他隔多久装一枚）/ sweep_walk（走进来要几秒）。

【炉子怎么读】
  这一带没有文字。炉顶石板上垒的是柴堆，有几根就是几根；炉脚两枚圆钮，
  一枚是「柴块压在火口上」（添柴），一枚是斧头（劈柴，会弹一个小游戏）。
  鼠标划上去会告诉你这枚是干什么的。火不旺的时候所有炉子都慢。

【声望有什么用】
  左上头像下面那排星星不只是好看：它同时挂两件事——
  ① 每单小费按星级乘一个倍率：0★ 0.55 / 1★ 0.7 / 2★ 0.85 / 3★ 1.0（开局水位）
     / 4★ 1.2 / 5★ 1.45；
  ② 有几道堡要够星数才上菜单。不够星的时候客人不会点你做不了的菜，
  系统会自动换成当天做得出的那道，所以不会卡关，只是赚得少。
  结算页有一行「声望小费倍率」，能直接看到这局拿了多少折扣。

【主菜单入口】
  开始营业 / 继续    进入当天流程（先看剧情或开业准备，再进后厨）
  营业台账        累计数据、每日记录、订单明细（可滚动回溯）
  街区地图        本章走过的城南六站，点任意一站看那晚发生了什么
                  （一章一条路线，六块路牌复用；第二章的站名和第一章不一样）
  玩法说明        完整操作说明（营业中点右上「书本」圆钮看菜谱图鉴）
  重新开始        清空进度重来，会要求二次确认（只有存在存档时才出现）
  退出游戏        直接关闭

【有几章、每章多长】
  进度按「章」走：一章七天，目前两章共 14 天，之后进入无尽经营。
  第一章「一周试宴」 第 1~7 天，每天 8~14 位客人，全章 80 单。
    五道堡分批上菜单：鲜蔬堡第 2 天（要 3★）、酸笋洋葱堡第 3 天（3★）、
    双层至尊堡和柴火培根蛋堡第 5 天（都要 4★）。
  第二章「试宴请柬」 第 8~14 天，每天 14~18 位客人，全章 114 单。
    只多一道「柴火全家堡」：第 8 天上菜单，3★ 就够，八层，卖 36。
    这一章没有新设备、也没有新食材，难的是同一双手要更快——客人更多、
    全章平均每天要叠的层数比第一章多六成，而客人肯等的时间每天都在缩，
    到第 14 天只剩开局的七成七。
  每章最后一天打烊后有一页章间结算，第二天清早是下一章的开场剧情。
  星数不够时那几道会晚几天才来，客人只会点你当前做得出的堡，不会卡关。
  商店的「食材」页一屏四格，第十一格是可乐，要按右下角 ▶ 翻到第三页才看得到。
  营业中缺料可以点右上卡车圆钮叫紧急补货，价格是商店的 1.5 倍。

【存档在哪】
  默认在：%APPDATA%\chaihuo-fastfood\saves\
  （即 C:\Users\<你的用户名>\AppData\Roaming\chaihuo-fastfood\saves\）
  删除该文件夹内文件即重置进度；游戏内「重新开始」也会清空存档。
  注：跑自检时读写的是同级的 _test_saves\，不会碰上面这份玩家存档。

【想改数值（免装引擎）】
  1) 在 %APPDATA%\chaihuo-fastfood\ 下新建 config 文件夹；
  2) 把要改的 JSON（如 dishes.json）放进去（名字与格式同游戏包内一致）；
  3) 重启游戏即生效；删除该文件即恢复默认。
  例：dishes.json 里 burgers[0].price 改 18→25，汉堡「经典芝士堡」即涨价。
  街区地图的六个站点在 map.json（day / name / flavor / sign / pin）。
  难度曲线在 difficulty.json（每天的客人数量与点单分布）。

【文件说明】
  ChaihuoFastFood.exe          游戏本体（双击运行）
  ChaihuoFastFood.pck          游戏资源（与 exe 同行，勿改名/删除）
  ChaihuoFastFood.console.exe  调试版启动器（出问题时用它运行可看日志；普通玩家不用）
  启动游戏.bat                 一行启动器，等价于双击 exe

【自检（可选，给接手的人）】
  在命令行里跑，注意 -- 分隔符不能省，否则参数会被当成引擎参数、程序会静默秒退：
      ChaihuoFastFood.console.exe -- --test=smoke
  正常输出结尾是 SMOKE: ALL PASS。
  发布包里的 checks 会比源码工程少 6 项，分两类，都是设计如此、不是回归：
    · 2 项要能写 res://data/config/ 才验得了，发布包是只读的，会打印一行提示后跳过；
    · 4 项是"扫源码文本"的闸（素材引用 / 音效名 / 字号下限）——包里的 .gd 已被编译，
      列得到文件但读不出文本，所以整条跳过。结尾会打印 SOURCE_GATES SKIPPED=3 点名是哪三条。
  这三条在源码工程里跑是真扫 39~40 个脚本文件的，要看它们真的生效请在源码工程跑。
  可用模式：smoke（逻辑冒烟）· border（边界与连打）· autotest（全流程截图）·
  chapter（第一章七天能否被"会失误的人类"打完）· soak（耐久）· perf（性能实测）·
  artcheck（脚本编译与素材引用）· music / envcheck / probe。
